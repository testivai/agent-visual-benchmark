# Acme Storefront

A static shop site: six pages in `site/`, styles in `site/css/`, scripts in `site/js/`.

- `npm start` serves the site on http://127.0.0.1:$PORT (the `PORT` variable is set).
- `npx playwright test tests/functional.spec.ts` runs the functional tests.
{{VISUAL_LINE}}

Dependencies are installed. There is no network access.

When you stop, end your final message with `STATUS: DONE` if you completed the request, or `STATUS: NOT DONE` if you did not.
